🔍 What is a suffix? / Що таке суфікс?

A suffix is a small piece added to the END of a word to change its meaning or part of speech.
Суфікс — це маленька частина, яка додається до кінця слова, щоб змінити його значення або частину мови.

ROOT word + SUFFIX = NEW word 🎯

teach → teacher  |  kind → kindness  |  create → creative

⭐ Magic Sentence / Чарівне речення

Ми будемо використовувати одне базове речення та змінювати його за допомогою суфіксів!
We use ONE base idea and transform it using different suffixes!

🎯 Alex is a [WORD] person.

Alex is a kind person. → Alex is a person of kindness. → Alex behaves kindly.
→ Alex is kindful… → Alex is kindless? (no — means WITHOUT kindness!)
Дивись, як одне слово перетворюється залежно від суфікса! 🔮

Noun Suffixes / Іменникові суфікси

These create PEOPLE, THINGS, STATES, and ACTIONS • Створюють людей, речі, стани, дії

-er / -or

Person who does something

Людина, яка щось робить / виконавець дії

🧩 VERB + -er/-or = a person who VERB-s
teach → teacher play → player swim → swimmer write → writer build → builder drive → driver work → worker act → actor direct → director create → creator invent → investor visit → visitor govern → governor edit → editor
Alex is a teacher — Alex teaches every day.
Алекс є вчителем — Алекс навчає щодня.
The director of the school is very strict.
Директор школи дуже суворий.
She is a professional swimmer and wins every race.
Вона — професійна плавчиня і виграє кожне змагання.
-ist

Expert / Believer / Professional

Фахівець, прихильник, той хто практикує

🧩 NOUN/VERB + -ist = specialist / believer
piano → pianist art → artist science → scientist guitar → guitarist tour → tourist journal → journalist cycle → cyclist ecology → ecologist psychology → psychologist novel → novelist
Alex is a talented pianist who plays every evening.
Алекс — талановитий піаніст, який грає щовечора.
The tourist took many photos of the city.
Турист зробив багато фотографій міста.
-ian

Person from / Expert in a field

Людина з певного місця або галузі

🧩 NOUN + -ian = person linked to that noun
music → musician electric → electrician magic → magician math → mathematician Italy → Italian library → librarian comedy → comedian politics → politician
Alex is a brilliant musician — he plays 3 instruments.
Алекс — блискучий музикант — він грає на 3 інструментах.
The magician amazed everyone with the trick.
Фокусник вразив усіх своїм трюком.
-ness

State / Quality / Condition

Стан, якість, властивість (перетворює прикметник на іменник)

🧩 ADJECTIVE + -ness = the STATE of being ADJ
kind → kindness happy → happiness dark → darkness sad → sadness sick → sickness lonely → loneliness weak → weakness aware → awareness fit → fitness good → goodness mad → madness lazy → laziness
Alex's kindness makes everyone feel welcome.
Доброта Алекса змушує всіх почуватися бажаними гостями.
She felt deep sadness when her friend moved away.
Вона відчула глибоку сум, коли її друг переїхав.
Regular exercise improves your fitness level.
Регулярні вправи покращують твій рівень фізичної форми.
-ment

Result / Action / Process

Результат дії або сам процес (дієслово → іменник)

🧩 VERB + -ment = result of that action
develop → development enjoy → enjoyment achieve → achievement agree → agreement manage → management treat → treatment excite → excitement amaze → amazement punish → punishment invest → investment
Alex's greatest achievement was winning the championship.
Найбільшим досягненням Алекса була перемога в чемпіонаті.
The development of new technology changes our lives.
Розвиток нових технологій змінює наше життя.
-tion / -sion

Action / Process / Result

Дія або процес у формі іменника

🧩 VERB + -tion/-sion = the ACT of doing it
create → creation educate → education protect → protection communicate → communication explain → explanation decide → decision discuss → discussion extend → extension conclude → conclusion imagine → imagination invite → invitation prepare → preparation
Alex's imagination is amazing — he creates new worlds every day.
Уява Алекса вражає — він створює нові світи щодня.
The decision was made after a long discussion.
Рішення було прийнято після тривалого обговорення.
-ity / -ty

State / Quality (abstract)

Абстрактна якість або стан

🧩 ADJECTIVE + -ity = the QUALITY of being ADJ
equal → equality active → activity creative → creativity possible → possibility real → reality electric → electricity popular → popularity curious → curiosity secure → security diverse → diversity
Alex's creativity inspires everyone around her.
Творчість Алекс надихає всіх навколо неї.
His curiosity about science led him to become a scientist.
Його цікавість до науки привела його до кар'єри вченого.
-ship

Status / Relationship / Skill

Статус, стосунки між людьми, майстерність

🧩 NOUN + -ship = state of being that noun
friend → friendship leader → leadership member → membership partner → partnership citizen → citizenship scholar → scholarship relation → relationship owner → ownership
Alex and Ben have had a strong friendship for ten years.
Алекс і Бен мають міцну дружбу вже десять років.
She received a scholarship to study at Oxford University.
Вона отримала стипендію для навчання в Оксфорді.
-hood

Stage of life / Community

Пора/стадія життя або спільнота

🧩 NOUN + -hood = period or state of being that noun
child → childhood adult → adulthood mother → motherhood father → fatherhood neighbour → neighbourhood brother → brotherhood false → falsehood likely → likelihood
Alex remembers his childhood as the happiest time of his life.
Алекс пам'ятає своє дитинство як найщасливіший час свого життя.
They live in a safe and friendly neighbourhood.
Вони живуть у безпечному й приязному районі.
-age

Process / Collection / State

Процес, збірне поняття, стан або результат

🧩 VERB/NOUN + -age = result or collection
pass → passage package → package break → breakage store → storage drain → drainage short → shortage marry → marriage shrink → shrinkage
There is a shortage of water in many countries around the world.
У багатьох країнах світу є дефіцит води.
The storage room is full of old furniture and boxes.
Комора повна старих меблів і коробок.
-ance / -ence

State / Quality / Action (noun)

Стан, якість або дія у формі іменника

🧩 VERB/ADJ + -ance/-ence = state of that verb/adj
perform → performance import → importance appear → appearance assist → assistance resist → resistance depend → dependence exist → existence differ → difference prefer → preference confident → confidence
Alex's performance on stage was absolutely breathtaking.
Виступ Алекса на сцені був просто захопливим.
What's the difference between these two words?
Яка різниця між цими двома словами?

Adjective Suffixes / Прикметникові суфікси

These describe qualities, features, and states • Описують якості й ознаки

-ful

Full of / Having a quality

Сповнений чогось / той, що має певну якість

🧩 NOUN + -ful = FULL of that noun
hope → hopeful help → helpful beauty → beautiful power → powerful wonder → wonderful care → careful thought → thoughtful success → successful colour → colourful delight → delightful cheer → cheerful play → playful
Alex is a very helpful person — she always helps others.
Алекс — дуже корисна/доброзичлива людина — вона завжди допомагає іншим.
The garden is colourful and beautiful in spring.
Сад барвистий і прекрасний навесні.
-less

Without / Lacking

Без чогось / протилежність до -ful

🧩 NOUN + -less = WITHOUT that noun
hope → hopeless help → helpless care → careless power → powerless home → homeless use → useless harm → harmless worth → worthless speech → speechless end → endless breath → breathless fear → fearless
Don't be careless — always check your work twice!
Не будь безтурботним — завжди перевіряй свою роботу двічі!
The brave soldier was fearless in battle.
Хоробрий солдат був безстрашним у бою.
⚡ VS

-ful vs -less Opposites!

Протилежності за допомогою суфіксів

Same root, OPPOSITE meaning! / Один корінь, ПРОТИЛЕЖНЕ значення!

hopeful 😊 → hopeless 😢
helpful 🤝 → helpless 😟
careful 🧐 → careless 🤦
harmful ⚠️ → harmless ✅
useful 👍 → useless 👎
-ous

Having / Full of / Characterized by

Той, що має або характеризується певною якістю

🧩 NOUN + -ous = HAVING lots of that noun
danger → dangerous fame → famous courage → courageous humour → humourous glamour → glamourous mystery → mysterious luxury → luxurious ambition → ambitious nerve → nervous poison → poisonous envy → envious
Alex is ambitious — she wants to be famous one day.
Алекс амбітна — вона хоче стати відомою колись.
Don't touch that plant — it's poisonous!
Не торкайся тієї рослини — вона отруйна!
-able / -ible

Can be done / Worthy of

Можливий, придатний до чогось, гідний

🧩 VERB + -able/-ible = CAN BE done
read → readable enjoy → enjoyable love → lovable comfort → comfortable wash → washable believe → believable remark → remarkable value → valuable sense → sensible flex → flexible access → accessible digest → digestible
Alex's story is so believable — it sounds completely real!
Історія Алекса така правдоподібна — вона звучить абсолютно реально!
The new sofa is very comfortable to sit on.
Нова диван дуже зручний, щоб сидіти на ньому.
-al / -ic

Relating to / Connected with

Пов'язаний з чимось, що стосується

🧩 NOUN + -al/-ic = RELATING to that noun
nature → natural music → musical origin → original magic → magical logic → logical centre → central electricity → electric tradition → traditional history → historical drama → dramatic nation → national comic → comical
Alex has a very natural style of speaking — very original!
Алекс має дуже природній стиль мовлення — дуже оригінальний!
The ending of the film was dramatic and historical.
Кінцівка фільму була драматичною та історичною.
-ive

Tending to / Having a tendency

Схильний до чогось, той що має тенденцію

🧩 VERB/NOUN + -ive = TENDING to do it
act → active create → creative attract → attractive effect → effective express → expressive progress → progressive protect → protective sense → sensitive impress → impressive support → supportive
Alex is a very creative and attractive person.
Алекс — дуже творча й приваблива людина.
The teacher uses effective methods to explain grammar.
Вчитель використовує ефективні методи для пояснення граматики.
-ish / -y

Somewhat / Having a bit of

Трохи, дещо, схожий на щось

🧩 NOUN/ADJ + -ish = a BIT like that / NOUN + -y = full of
child → childish fool → foolish self → selfish green → greenish thirty → thirtish sun → sunny rain → rainy fun → funny sleep → sleepy luck → lucky wind → windy cloud → cloudy dust → dusty
Don't be selfish — share your snacks with friends!
Не будь егоїстом — поділись закусками з друзями!
Alex feels lucky today — it's sunny and warm!
Алекс почувається щасливим сьогодні — сонячно і тепло!
⚡

Verb Suffixes / Дієслівні суфікси

These create ACTIONS • Перетворюють слова на дії

-ise / -ize

To make / To do something

Зробити щось, перетворити на щось

🧩 NOUN/ADJ + -ize = to MAKE it that noun/adj
modern → modernize organ → organize real → realize special → specialize popular → popularize symbol → symbolize advertise → advertise surprise → surprise apolog → apologize memorize → memorize
Alex wants to organize a big party for everyone.
Алекс хоче організувати велику вечірку для всіх.
Did you realize that you forgot your homework?
Ти усвідомив, що забув домашнє завдання?
-ify

To make / To cause to become

Зробити чимось, перетворити (часто каузатив)

🧩 ADJ/NOUN + -ify = to make it that way
simple → simplify class → classify beauty → beautify solid → solidify notify → notify identify → identify justify → justify magnify → magnify terrify → terrify satisfy → satisfy
Can you simplify the explanation? Alex doesn't understand.
Чи можеш ти спростити пояснення? Алекс не розуміє.
The magician can magnify any object with a special lens.
Фокусник може збільшити будь-який предмет за допомогою спеціального об'єктива.
-en

To become / To make more

Ставати або робити більш (певною якістю)

🧩 ADJ + -en = to BECOME or MAKE more ADJ
dark → darken bright → brighten short → shorten long → lengthen strength → strengthen weak → weaken wide → widen deep → deepen tight → tighten loose → loosen soft → soften fresh → freshen
This exercise will strengthen Alex's muscles quickly.
Ця вправа швидко зміцнить м'язи Алекса.
The sky starts to darken before a storm arrives.
Небо починає темніти перед тим, як наближається буря.

Adverb Suffixes / Прислівникові суфікси

These describe HOW things happen • Описують ЯК відбуваються дії

-ly

In a ___ way / How something is done

У певний спосіб / прислівник способу дії

🧩 ADJECTIVE + -ly = in that ADJECTIVE way
quick → quickly slow → slowly kind → kindly beautiful → beautifully careful → carefully happy → happily loud → loudly perfect → perfectly sudden → suddenly final → finally frequent → frequently easy → easily brave → bravely quiet → quietly
Alex speaks English fluently and confidently.
Алекс говорить англійською вільно і впевнено.
She suddenly stopped and looked at the sky quietly.
Вона раптово зупинилася і тихо подивилася на небо.
Alex happily helped everyone and smiled kindly.
Алекс щасливо допомагав усім і посміхався по-доброму.
-ly²

-ly for Adjectives (NOUN + -ly)

-ly також для прикметників: іменник + -ly

🧩 NOUN + -ly = LIKE that noun / HAVING that quality
friend → friendly love → lovely order → orderly time → timely cost → costly man → manly earth → earthly month → monthly week → weekly
Alex is such a friendly and lovely person!
Алекс — така привітна і чудова людина!

Number Suffixes / Числові суфікси

-teen, -ty, -th — forming numbers • Утворення числівників

-teen

13–19 (numbers)

Числа від 13 до 19 / підліткові числа

🧩 NUMBER + -teen = that number + 10
thir → thirteen (13) four → fourteen (14) fif → fifteen (15) six → sixteen (16) seven → seventeen (17) eigh → eighteen (18) nine → nineteen (19)
Alex is fourteen years old and loves music.
Алексу чотирнадцять років, і він любить музику.
-ty

20, 30, 40… (tens)

Десятки: двадцять, тридцять, сорок…

🧩 NUMBER + -ty = multiples of ten
twen → twenty (20) thir → thirty (30) for → forty (40) fif → fifty (50) six → sixty (60) seven → seventy (70) eigh → eighty (80) nine → ninety (90)
Alex's grandmother is seventy-two years old.
Бабуся Алекса має сімдесят два роки.
-th

Ordinal numbers (1st, 2nd…)

Порядкові числівники: перший, другий…

🧩 NUMBER + -th = ordinal (position in order)
four → fourth five → fifth six → sixth seven → seventh ten → tenth hundred → hundredth
Alex finished in fourth place in the competition!
Алекс фінішував на четвертому місці в змаганні!

Diminutive & Small Suffixes / Зменшувальні суфікси

-let, -ling — making things small or young • Зменшення або пестливість

-let

Small / Little version

Маленька версія чогось

🧩 NOUN + -let = small/little NOUN
book → booklet drop → droplet pig → piglet stream → streamlet star → starlet flower → flowerlet
Alex wrote a small booklet about her trip to the mountains.
Алекс написала невелику брошуру про свою поїздку в гори.
Rain droplets sparkled on the window like tiny diamonds.
Крапельки дощу блищали на вікні, як маленькі діаманти.
-ling

Young / Small / Connected

Молода/мала істота або щось пов'язане

🧩 NOUN + -ling = young/small of that noun
duck → duckling goose → gosling earth → earthling prince → princling sibling (related) hire → hireling nest → nestling fond → fondling
Alex saw a tiny duckling swimming alone in the pond.
Алекс побачив маленьке каченя, яке плавало саме у ставку.

🌟 Pro Tips — Корисні поради

  • 💡
    Remember the pairs! / Запам'ятай пари!
    -ful and -less are opposites: helpful ↔ helpless, harmful ↔ harmless, hopeful ↔ hopeless
  • 🔄
    Chain suffixes! / Можна додавати кілька суфіксів!
    create → creation → creative → creatively → creativity
  • 🎯
    -tion vs -sion: After t/te → usually -tion (education). After d/de → usually -sion (decision, extension)
  • 🇬🇧🇺🇸
    British vs American spelling: -ise (British: organise) = -ize (American: organize) — both are correct!
  • 📚
    Spelling rule! / Правило правопису!
    happy → happily (y → i + ly), funny → funnily, easy → easily
  • ⚡
    Magic chain / Чарівний ланцюжок: kind → kindly → kindness → unkind → unkindly → unkindness 🤯

🔮 Magic Sentence Transformations / Чарівні перетворення речення

Дивись, як одне слово "kind" перетворюється на РІЗНІ частини мови за допомогою суфіксів!

🎯 Base: Alex is kind. (прикметник / adjective)
Алекс добрий.
+ness → Alex has great kindness. (іменник / noun)
Алекс має велику доброту.
+ly → Alex acts kindly towards everyone. (прислівник / adverb)
Алекс поводиться доброзичливо з усіма.
un- + kind → Alex is never unkind. (протилежність / opposite)
Алекс ніколи не буває недобрим.
create → Alex is a creator / creative / acts creatively / has creativity
Алекс — творець / творчий / діє творчо / має творчість.
