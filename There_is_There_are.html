There is &
There are

Learn when to say "There IS" and when to say "There ARE" — with examples, formulas, and fun! Коли казати «There IS», а коли «There ARE» — з формулами, прикладами та картинками!

📌 What does it mean?
Що це означає?
🌍

We use it to say something EXISTS somewhere

We use There is / There are to tell people that something or someone is in a place, or that it exists. Ми використовуємо There is / There are, щоб сказати, що щось або хтось знаходиться десь, або просто існує.

Think of it like pointing at something: "Look! THERE IS a cat!" Уявіть, що ви вказуєте на щось: «Дивись! ТАМ Є кіт!»

⚡ The Golden Rule
Золоте правило
There IS
Use with ONE thing (singular noun)Використовуй з одним предметом (однина)
There is + 1 thing
🐈 There is a cat in the room.У кімнаті є кіт.
☕ There is a cup on the table.На столі є чашка.
There ARE
Use with TWO or MORE things (plural noun)Використовуй з двома або більше предметами (множина)
There are + 2+ things
🐈🐈 There are two cats in the room.У кімнаті є два коти.
☕☕ There are three cups on the table.На столі є три чашки.
🎯 One Universal Sentence
Одне універсальне речення — яке змінюється залежно від ситуації

⭐ Watch how it changes!

Дивись, як речення змінюється залежно від кількості та типу висловлювання
✅ Positive · Стверджувальне
There is a book on the desk.
There are books on the desk.
На столі є книга. / На столі є книги.
❌ Negative · Заперечне
There isn't a book on the desk.
There aren't any books on the desk.
На столі немає книги. / На столі немає книг.
❓ Question · Питальне
Is there a book on the desk?
Are there books on the desk?
На столі є книга? / На столі є книги?
📚 All Cases Explained
Усі можливі випадки вживання

There IS — Singular (Однина)

Use when there is exactly ONE thing.Використовуй, коли є рівно ОДИН предмет.
There is + a/an + noun (singular) + place
IS
🐕 There is a dog in the garden.
У саду є собака.
IS
🏠 There is a house on the hill.
На пагорбі є будинок.

There ARE — Plural (Множина)

Use when there are TWO or MORE things.Використовуй, коли є ДВА або БІЛЬШЕ предмети.
There are + number/some + noun (plural) + place
ARE
🐕🐕 There are two dogs in the garden.
У саду є два собаки.
ARE
🏠🏠 There are some houses on the hill.
На пагорбі є кілька будинків.

There ISN'T — Singular (Однина)

Use to say ONE thing does NOT exist somewhere.Використовуй, щоб сказати, що одного предмета немає.
There isn't + a/an + noun (singular) + place
ISN'T
🚫🐕 There isn't a dog in the garden.
У саду немає собаки.
ISN'T
🚫🏠 There isn't a house on the hill.
На пагорбі немає будинку.

There AREN'T — Plural (Множина)

Use to say MULTIPLE things do NOT exist. We add "any".Для множини. Додаємо «any» (жодних).
There aren't + any + noun (plural) + place
AREN'T
🚫🐕🐕 There aren't any dogs in the garden.
У саду немає жодного собаки.
AREN'T
🚫🏠🏠 There aren't any houses on the hill.
На пагорбі немає будинків.

Is there…? — Singular (Однина)

To ask about ONE thing, put IS before THERE.Щоб запитати про один предмет, став IS перед THERE.
Is there + a/an + noun (singular) + place + ?
QUESTION
❓ Is there a dog in the garden?
У саду є собака?
QUESTION
❓ Is there a park near here?
Тут поруч є парк?

Are there…? — Plural (Множина)

To ask about MULTIPLE things, put ARE before THERE.Щоб запитати про кілька предметів, став ARE перед THERE.
Are there + any + noun (plural) + place + ?
QUESTION
❓ Are there any dogs in the garden?
У саду є собаки?
QUESTION
❓ Are there any parks near here?
Тут поруч є парки?

💬 Short Answers — Короткі відповіді

In English we don't repeat the full sentence — we use short answers!В англійській не повторюємо все речення — даємо коротку відповідь!
YES ✅
Yes, there is.
Yes, there are.
NO ❌
No, there isn't.
No, there aren't.
Q Is there a dog in the garden?  A Yes, there is. 🐕— У саду є собака? — Так, є.
Q Are there any books on the shelf?  A No, there aren't. 📚— На полиці є книги? — Ні, немає.

💡 Remember These Tips!
Запам'ятай ці підказки!
1️⃣

ONE = IS

If you can count just one thing → use There IS.Якщо один предмет → There IS

🔢

MANY = ARE

If there are 2, 3, or more → use There ARE.Якщо 2, 3 або більше → There ARE

❓

Questions: flip!

Swap the order: IS/ARE + THERE + noun?У запитанні: IS/ARE ставимо перед THERE

🎯

Use "any" in ❌ & ❓

In negatives & questions (plural), add ANY before the noun.У запереченні та запитанні (множина) додай ANY
